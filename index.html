How to enter
• Write the address first, then the amount, one recipient per line. Separate them with a comma, semicolon, space or tab.
• Use a dot for decimals: 0.5. Do not use thousand separators: write 1000, not 1,000.
• In Excel, put addresses in column A and amounts in column B, use Save As → CSV, then choose the file with “Upload CSV / TXT”. A header row is skipped automatically.
• Amounts are in token units (e.g. write 10 to send 10 USDT).
